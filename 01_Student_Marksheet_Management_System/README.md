## 3. Project Overview

The Student Marksheet Management System is an Excel-based project designed to manage student academic records, calculate examination marks, and evaluate student performance.

The system includes 208 students from Class 10, divided into four divisions: A, B, C, and D.

Excel functions are used to automate marks calculation, percentage calculation, grading, ranking, result determination, and performance evaluation. This project helps reduce manual calculations, improve accuracy, and organize student academic information in a structured format.

---

## 4. Project Overview

- Manage academic records of 208 students.
- Organize students into four divisions: A, B, C, and D.
- Calculate subject-wise obtained marks and total marks.
- Calculate average marks and percentages.
- Identify the highest and lowest marks.
- Assign grades based on student performance.
- Calculate student ranks.
- Determine Pass or Fail results.
- Categorize students based on their academic performance.
- Reduce manual calculations and calculation errors.

## 5. Excel Functions Used

The project uses Excel functions to automate calculations and student performance evaluation.

| Function | Purpose |
|---|---|
| `SUM()` | Calculate total obtained marks |
| `AVERAGE()` | Calculate average marks |
| `MAX()` | Find highest marks |
| `MIN()` | Find lowest marks |
| `IF()` | Assign grades, results, and performance |
| `RANK.EQ()` | Calculate student rank |
| `COUNT()` | Count numeric values |
| `COUNTA()` | Count non-empty records |
| `COUNTIF()` | Count students based on a condition |
| `COUNTIFS()` | Count students based on multiple criteria |
| `IFERROR()` | Handle formula errors |
